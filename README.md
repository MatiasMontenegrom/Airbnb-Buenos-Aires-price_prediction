# Airbnb Buenos Aires Price Prediction

Proyecto de regresion para explorar y predecir precios de alojamientos de Airbnb en Buenos Aires.

## Estructura

- `data/raw/`: datos originales. El archivo disponible es `listings.csv`.
- `data/processed/`: datos preparados para el modelado.
- `notebooks/`: analisis y desarrollo ordenados por etapa.
- `src/`: codigo reutilizable de preprocesamiento, features, evaluacion y entrenamiento.
- `models/`: artefactos de modelos entrenados.
- `results/`: figuras y metricas generadas durante el analisis.

## Inicio

Instala las dependencias con `pip install -r requirements.txt` y abre los notebooks con Jupyter.

> El archivo de vuelos `Flight_Price_Prediction.csv` del esquema de referencia no estaba disponible. No se renombro `listings.csv`, ya que contiene datos de Airbnb.
